# 家計簿バックエンド (Expense Tracker API)

このプロジェクトはSpring Bootを使用して作成した、個人向けの家計簿アプリのバックエンドです。

## 機能
- ユーザー登録・ログイン機能
- 収支データの追加・取得・管理
- PostgreSQLデータベース連携
- REST APIによる設計

## 使用技術
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security（基本設定）
- PostgreSQL
- Maven

## 目的
バックエンド開発の学習と実践的な金融管理システムの構築を目的としています。
